# DOSCIENTOS

**Año 2100 · película futurista · 30 minutos · 16:9**

El hijo del obrero puede gobernar. El hijo del gobernante puede ser obrero, si eso quiere.

Sala de proyección con el corte completo (voz en pantalla, catorce cuadros, Marte y Encélado). Este repositorio guarda el guion cerrado y la ficha lista para YouTube.

Un máster 4K de media hora pesa más de lo que GitHub acepta en un solo archivo (límite 100 MB). Por eso la película se proyecta en la sala, y aquí queda el texto para publicarla.
